# Runner Game

A 3D runner-game project built with Godot 4.6 and configured for C#/.NET. This repository contains the game project and platformer assets used during development.

## Tech and tools
- Godot Engine 4.6
- C# / .NET
- Godot scenes and imported assets
- Kenney platformer assets (see the included asset license)

## Run the game
1. Install Godot 4.6 with .NET support.
2. Clone this repository.
3. Open `runner/project.godot` in Godot.
4. Allow the editor to import the project.
5. Run the main scene from the editor.

## Repository structure
- `runner/` — Godot game project
- Asset folders — models, textures, and other game resources
